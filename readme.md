📅 SISTEMA DE AGENDAMENTO DE REUNIÕES

---

Proposta do Projeto

O projeto tem como objetivo principal a criação de um sistema de agendamento de reuniões, tanto online quanto presencial. O sistema foi desenvolvido para facilitar a organização de horários e melhorar a comunicação entre usuários, oferecendo uma plataforma simples, funcional e acessível.

Descrição do Projeto

O sistema permite realizar agendamentos de reuniões de forma prática e organizada. O usuário pode:

· Agendar reuniões com título, descrição, data, horário e local
· Editar reuniões existentes
· Cancelar reuniões
· Exportar todos os dados em formato JSON
· Visualizar reuniões em uma lista organizada por data e horário

Tecnologias utilizadas:

· Python e Flask para o back-end e rotas da API
· SQLite como banco de dados para armazenamento
· HTML, CSS e JavaScript para o front-end e interface do usuário
· Render para hospedagem do site na nuvem
· Git e GitHub para versionamento e integração contínua

---

Ciclo de Desenvolvimento

1. Idealização – Começamos com a ideia principal e criamos um esboço inicial.
2. Base e modelo – Utilizamos como base um modelo pré-definido de um site de salão de beleza e adaptamos conforme as necessidades do projeto.
3. Desenvolvimento – Partimos para a criação do HTML e desenvolvimento das demais funcionalidades do sistema.
4. Banco de dados – Implementamos o SQLite para persistência dos dados.
5. Hospedagem – Publicamos o site no Render com integração contínua via GitHub.
6. Finalização – Adicionamos tela de carregamento, popups de notificação e exportação em JSON.

---

Futuro do Projeto

Pretendemos aprimorar a estrutura do site, adicionar novas funcionalidades como autenticação de usuários e notificações, e utilizá-lo como portfólio em nossos currículos no futuro.
